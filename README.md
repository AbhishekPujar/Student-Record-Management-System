
# Student Record Management System

## Project Description
This is a Python-based Student Record Management System.
It helps users manage student information using CRUD operations.

## Features
- Add student records
- View all student records
- Search student records
- Update student information
- Delete student records
- Store records in JSON format
- Export records to CSV
- Exception handling
- Input validation

## Technologies Used
- Python
- JSON
- CSV
- Visual Studio Code

## Python Concepts
- Functions
- Parameters and Return Values
- Lambda Functions
- List Comprehension
- File Handling
- Exception Handling
- Virtual Environment

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run: `python3 main.py`
